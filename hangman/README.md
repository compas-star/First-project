# 🎯 Виселица

Игра «Виселица» на двоих: один игрок вписывает загаданное слово (ввод скрыт точками,
рядом есть кнопка «глаз»), второй нажимает на буквы. Верная буква открывается в слове,
неверная — дорисовывает виселицу. 11 ошибок — и человечек нарисован полностью.

Особенности:
- один файл `index.html`, без сборки и зависимостей;
- алфавит подставляется автоматически — русский или английский, по загаданному слову;
- Ё и Е считаются одной буквой (в ответе Ё показывается как есть);
- пробелы и дефисы открыты сразу, слова не разрываются при переносе строки;
- можно играть с телефона (крупные кнопки) и с компьютера (обычная клавиатура).

Открыть: https://compas-star.github.io/First-project/hangman/

Локально: просто открыть `index.html` в браузере.
