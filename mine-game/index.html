Песчаная шахта

Деньги: 0 По плану: 0 Золото: 0 / 0 Рабочие: 0

Цель: добыть золото из жилы в правом нижнем углу и никого не похоронить.

Ствол — вертикальная шахта с лестницей, тяните от поверхности вниз. Штрек — горизонтальный тоннель, тяните вдоль пола. Крепь — деревянная рама, кликните по тоннелю. Рабочие выполняют план по порядку, а готовую крепь ставят в первую очередь.

Длинный незакреплённый пролёт осыпается, песок из линз течёт в выработки, камень копается долго и дорого. Завалы рабочие разбирают сами, но за деньги. План можно править и во время работы.
