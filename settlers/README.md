# Эпохи Племени

Мобильная браузерная игра: вид сверху 3/4, ведёшь поселенца пальцем, ресурсы добываются автоматически.

Запуск локально: `python3 -m http.server` в этой папке, затем открыть `index.html`.

## Код
- `js/core.js` — пространство имён `S`, математика, шум, джойстик и клавиатура
- `js/data.js` — эпохи, постройки и их уровни, планировка лагеря, характеристики юнитов, цели обучения
- `js/world.js` — генерация карты, ресурсы, поиск пути (A*), отрисовка земли, миникарта
- `js/units.js` — игрок, работники, поселенцы, звери, воины соседей, бой
- `js/build.js` — постройки и площадки, соседнее племя, день и ночь, набеги, цели
- `js/render.js` — вся графика
- `js/main.js` — цикл, интерфейс, сохранение

## Версия 0.1
Добыча, лагерь и площадки, поселенцы-работники, волки, медведи, олени, ночные набеги, вышки и частокол,
соседнее племя, эпохи (каменный век → бронзовый → феодализм), чудеса и очки богов, обзорная карта.
