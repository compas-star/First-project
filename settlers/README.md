# Эпохи Племени

Мобильная браузерная игра: вид сверху 3/4, ведёшь поселенца пальцем, ресурсы добываются автоматически.

Запуск локально: `python3 -m http.server` в этой папке, затем открыть `index.html`.

## Код
- `js/core.js` — пространство имён `S`, математика, шум
- `js/data.js` — эпохи, люди, здания, чудеса, улучшения, цели, планировка лагеря
- `js/economy.js` — экономика без DOM: доход, цены, покупки, тапы, баффы, доход без игрока
- `js/world.js` — генерация карты, ресурсы, поиск пути (A*), отрисовка земли
- `js/units.js` — видимые работники, волки, золотой олень, стрелы
- `js/city.js` — что стоит в лагере, вышки, события, тапы и комбо, день и ночь
- `js/render.js` — графика
- `js/ui.js` — верхняя панель, магазин, окна
- `js/main.js` — камера, цикл, звук, сохранение

## Версия 0.2: кликер-стратегия
Тапаешь по лесу, кустам и камням, комбо до ×2 (×3 с навыком). Нанимаешь людей, они видны на карте и сами
носят ресурсы. Здания с бесконечными уровнями и вехами ×2 на 10/25/50/100. Навыки ×2, золотой олень (баффы),
волки (тапай или строй вышки и частокол), цели с наградами, чудеса в 5 этапов, три эпохи, доход без игрока до 8 часов.
